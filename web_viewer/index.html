Overlay placement uses one bounding box per footprint (path/row), taken from a single date's CBERS metadata and reused across all dates on that footprint. CBERS track stability is ~±5km pass-to-pass, so this is a reasonable demo-quality placement, not pixel-exact per-date georeferencing. Marker accuracy is exact for the two reference-date scenes; other dates show a documented positional approximation.
